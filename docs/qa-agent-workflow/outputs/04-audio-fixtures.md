## Provenance and change control

Once approved and created, never silently replace fixture bytes. Record checksum, codec, sample rate, channels, duration, size, source, and checked reference text. Changes update the manifest and corresponding expected results together. The Upload and Live stable regression must reference the same primary SHA-256.

For a real-provider review, confirm pronunciation is clear enough for the selected language pair and use the reference to check the facts, not punctuation or one canonical wording. Never use patient recordings, real WhatsApp audio, personal messages, or an unlicensed third-party recording.
